# First Collection Physical Proof Order Plan

Status date: 2026-11-15

Forge & Verse now has twelve physical product candidates prepared for a first manufacturing or material proof: three in each professional room.

This document is an internal studio order guide. It does not mark any edition or product as approved for public sale.

## The gate

A production file may be **proof-order-ready** without being **Studio proof approved**.

The sequence remains:

1. Design and produce the manufacturing file.
2. Order the first physical proof.
3. Handle, write in, hang, light, and photograph the real object.
4. Record changes.
5. Order a revised proof when needed.
6. Only after approval, lock the production configuration and move the product toward public availability.

## Pads

Working first-choice proof vendor: Captain Notepad.

Current reasons for the proof phase:
- 4 x 6 and 5 x 7 are standard offered sizes.
- Their bulk-product guidance says most sizes begin around 8–12 pads; the 4 x 6 Best Value option starts at 9.
- 25- and 50-sheet pad options are available.
- Chipboard backing and multiple uncoated paper weights are available.
- Up to three proofs are included before printing.

Current vendor entry:
https://www.captainnotepad.com/bulk-custom-notepads/products/

### First pad order

Use the smallest practical quantity in each size, 25 sheets per pad, standard uncoated paper for the first test, no magnet, and top glue.

Do not optimize unit cost yet. The first order is buying information.

### Pad acceptance test

For every pad:
- write with ballpoint, gel, rollerball, and pencil;
- write quickly and with deliberately large handwriting;
- tear sheets from the front, middle, and back;
- use the pad at a real desk for several days;
- check whether the glue edge curls or interferes with the first field;
- photograph the pad clean, partially used, and in its intended environment.

## Bound notebooks

Working first-choice proof vendor: Printivity Wire-O or Spiral Bound Booklets.

Current file geometry:
- finished trim: 5.5 x 8.5 inches;
- submitted production file: 5.75 x 8.75 inches to provide 0.125 inch bleed on all four edges;
- single pages in reading order;
- critical content kept away from the binding edge;
- full cover and interior contained in one PDF.

Current vendor guidance:
https://www.printivity.com/insights/how-to-make-a-spiral-bound-booklet
https://www.printivity.com/help-center/file-design-questions

Before paying for production, use Printivity's complimentary file check / digital proof process. Ask for or quote the smallest practical Wire-O or spiral sample; a hardcopy proof is preferable when available for the configured order.

### First notebook order

Start with:
- 5.5 x 8.5 finished size;
- Wire-O if available at a sensible proof cost; spiral/coil is acceptable if it gives a better low-quantity test;
- uncoated writable interior;
- dark durable cover;
- no premium coating on interior pages.

The first goal is not luxury. It is to learn whether the trim, binding, paper, page mix, and cover construction deserve another round.

### Notebook acceptance test

For every notebook:
- write near the binding with the dominant and non-dominant hand;
- test several pens and pencil;
- inspect show-through and bleed-through;
- leave the book open on a desk and test whether it stays put;
- use each ruling treatment long enough to become annoying if it is going to be annoying;
- photograph cover, binding, structured pages, ordinary writing pages, and an actual in-use spread.

## Wall material proofs

Working first-choice proof vendor: Bay Photo.

The wall files are deliberately small material proofs rather than final large editions. The point is to decide surface, black behavior, glare, typography, and whether the composition earns a larger mounted proof.

Current vendor entry:
https://bayphoto.com/wall-displays/metalprints/

Bay Photo currently offers standard MetalPrint surfaces including High Gloss, Mid-Gloss, Satin, Sheer Glossy, and Sheer Satin, with sample packs intended for comparing one image across surfaces.

### First wall order strategy

Do not buy twelve large wall panels.

Use small proofs:
- 8 x 12 for A Hash Is a Promise.
- 8 x 12 or custom/cropped equivalent for the three landscape pieces, preserving the composition rather than stretching it.
- Prefer Satin and Mid-Gloss as the first serious candidates for text-heavy office art.
- If one design is going to be used to learn all five metal surfaces, use a Bay Photo MetalPrint sample pack before committing the other editions.

The repository also contains 300 DPI JPG exports for the four wall proofs because Bay Photo's image-order workflow is better suited to print-ready raster uploads than to treating the studio PDF as a customer image.

### Wall acceptance test

For every wall proof:
- inspect head-on and at oblique angles under office lighting;
- check black separation rather than only overall darkness;
- read the main line from several feet away;
- inspect brass/oxblood color behavior;
- photograph front, angle, surface detail, and the piece in a realistic room;
- decide whether the composition deserves a larger proof before selecting final mounting.

## Believe in the Badge

The first physical proof is intentionally a new typography-led direction.

The prior 1536 x 1024 photographic backdrop remains too small for a premium large-format edition. The studio did not upscale it and call the problem solved.

The 12 x 8 proof asks a better question: can the original writing carry the piece through typography, proportion, and restrained abstract shield geometry?

If it succeeds, the final edition can grow from a clean vector foundation. A future photo-backed edition remains possible only if a genuinely suitable high-resolution source earns its place.

## Photography batch

After the proofs arrive, create one coordinated studio shoot rather than photographing products ad hoc.

Capture:
- clean product hero;
- hand / scale reference;
- close material detail;
- actual writing or use;
- environment / room;
- side profile for binding, chipboard, or wall depth;
- one imperfect real-use image that proves the object was handled rather than only staged.

These photographs should replace conceptual renders on product pages as each object moves through physical proof.

## Commercial decision after proof

For each product, record:
- proof vendor;
- exact stock / finish / binding / mount;
- proof cost;
- likely production quantity or fulfillment route;
- delivered quality;
- required revisions;
- target retail range;
- production partner suitability;
- whether the product advances, revises, or rests.

Do not set public pricing from mock production costs. Physical proof quality and the actual partner model come first.
