# Content Model

## Works

Works are the main studio archive. A work may be writing, art, a physical-edition study, a useful object, or a concept that has passed beyond a stray idea.

Required fields:

- `title`
- `summary`
- `discipline`
- `format`
- `format_label`
- `status`
- `rights`

Useful optional fields:

- `featured`
- `cover_style`
- `image`
- `image_alt`
- `series`
- `note`
- `external_url`
- `cta_label`

## Journal

Journal entries carry essays, field notes, professional observations, and design thinking. A journal entry can later inspire a separate Work entry without the two becoming the same page.

## Free Works

Free Works are direct releases. Each page should identify:

- what the files are
- intended use
- credit expectation
- file dimensions or print details
- any limitations on alteration, redistribution, or resale

## Disciplines

Discipline slugs are fixed because they drive filters and related content:

- `examiner-bench`
- `evidence-room`
- `watch`
- `signal`

Add a new discipline only when the studio has enough credible work to justify another room.
