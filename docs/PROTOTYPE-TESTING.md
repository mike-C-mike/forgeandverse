# Prototype Testing

A Forge & Verse study advances because it survives the moment it was designed for, not because the mockup looks finished.

## Bench Status Pad

### Print

Use `source-assets/prototypes/bench-status-pad-prototype-letter-2up.pdf` and print in landscape at 100 percent or Actual Size. Cut one proof to 4 x 6 inches.

### Test

1. Choose a realistic active-case scenario.
2. Complete the sheet while simulating the last five minutes of a shift.
3. Record how long completion takes.
4. Put the sheet away for at least forty-eight hours.
5. Return to it without reopening case notes first.
6. State the current process, last completed action, next action, and blocker aloud.
7. Mark any field that was ignored, cramped, ambiguous, or missing.
8. Securely destroy the test sheet if real case information was used.

### Pass condition

The examiner can recover the active case state in under thirty seconds without needing to decode the sheet.

## Examination Notebook

### Print

Use `source-assets/prototypes/examination-notebook-interior-prototype.pdf`. The current proof is 5.5 x 8.5 inches and is intended for page-architecture review, not case use.

### Test

1. Review the opening structured pages without filling every field.
2. Use the note-page proofs with at least three common pens.
3. Write continuously for twenty minutes on one page treatment.
4. Map a relationship or timeline on another treatment.
5. Judge line spacing, visual noise, bleed-through, page size, and hand comfort.
6. Identify any structured page that feels like duplicated software rather than useful orientation.
7. Confirm whether local policy allows the intended notebook workflow.

### Pass condition

The structure helps at the few moments where orientation matters, then disappears. The open pages remain the reason to carry the notebook.

## Advancing a study

Record:

- what was tested
- what changed
- what was removed
- what remains unresolved
- whether the release test passed

Do not advance a study because time has passed or because a category looks empty.
