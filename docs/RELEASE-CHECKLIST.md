# Release Checklist

## Words

- Title, summary, and description are final
- Punctuation and capitalization are consistent
- No em dashes unless deliberately chosen for the piece
- The page does not describe internal brand strategy
- Humor lands as affection, not ridicule

## Visuals

- Final image is correctly sized and compressed
- Text remains readable on mobile
- Alt text describes meaningful imagery
- Logo and studio mark reproduce cleanly
- Mockups do not imply an item is available when it is not

## Files

- Download links resolve
- Dimensions and formats are stated correctly
- Print files have sufficient resolution
- File names are descriptive and stable

## Rights

- Rights checklist is complete
- Source and license records are retained outside the public page
- Use guidance is present for free releases

## Site behavior

- Work appears in the correct discipline filter
- Related links are relevant
- External links open to the intended production partner
- Mobile navigation and keyboard focus remain usable
