# Release Checklist

## Curation gate

- The work exists because the studio believes in it, not because a category looks empty
- It is specific enough that the intended practitioner feels recognized
- A free release solves a real problem, improves a workflow, or is genuinely worth displaying
- A useful object begins with a real behavior rather than a themed cover

## Words

- Title, summary, and description are final
- Punctuation and capitalization are consistent
- No em dashes unless deliberately chosen for the piece
- The page does not describe internal brand strategy
- Humor lands as affection, not ridicule

## Visuals and physical form

- Final image is correctly sized and compressed
- Text remains readable on mobile and at intended viewing distance
- Alt text describes meaningful imagery
- Logo and studio mark reproduce cleanly
- Mockups do not imply an item is available when it is not
- Material, finish, mounting, crop, and edge behavior have been considered for wall editions

## Files and utility

- Download links resolve
- Dimensions and formats are stated correctly
- Print files have sufficient resolution
- Editable files open and render cleanly
- File names are descriptive and stable
- Operational templates state what local review or adaptation is required

## Rights

- Rights checklist is complete
- Source and license records are retained outside the public page
- Use guidance is present for free releases
- Adaptation permission is stated explicitly when provided

## Site behavior

- Work appears in the correct discipline
- Related links render only when genuinely related work exists
- External links open to the intended production partner
- Mobile navigation and keyboard focus remain usable
