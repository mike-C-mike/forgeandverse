Verification

A published hash is only useful when someone checks it.

Calculate the SHA-256 value of the file you received, then compare it with the value shown on the release page or in the ledger manifest. A mismatch means the file is not byte-for-byte identical to the published release.

Checksums establish file identity. They do not replace local malware scanning, source review, policy approval, or testing.

PowerShellGet-FileHash .\filename.zip -Algorithm SHA256
Windows built-incertutil -hashfile filename.zip SHA256
macOSshasum -a 256 filename.zip
Linuxsha256sum filename.zip
