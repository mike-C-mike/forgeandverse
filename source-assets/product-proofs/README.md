# Product proof source assets

This directory is generated by:

```bash
python scripts/build_product_proofs.py
```

The PDFs are manufacturing-test files for the Forge & Verse first collection. They are not public releases and do not imply that the product or physical configuration has been approved for sale.

The generator is deterministic where practical and writes `manifest.json` with byte counts and SHA-256 hashes.

## Current set

- four tear-away pad files;
- four 5.5 x 8.5 finished-trim bound notebook files;
- four small wall-material proof files;
- 300 DPI JPG exports for the wall proofs are generated during the proof-build workflow.

The bound notebook PDFs include 0.125 inch bleed on all sides, so their submitted page size is 5.75 x 8.75 inches for a 5.5 x 8.5 finished trim.

## Gate

A file in this directory may be **proof-order-ready** while the physical product remains **in the studio**.

Only a physically reviewed and approved configuration may later earn the public **Studio proof approved** signal.
