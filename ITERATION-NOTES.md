# Forge & Verse v14

This iteration turns the first free work from a single form into a complete operational release.

## Public changes

- Expanded the Digital Forensics Intake Request into the **Digital Forensics Intake Kit**.
- Added a one-page requester guide for officers and investigators.
- Added a four-page implementation guide for forensic units and agency administrators.
- Included editable DOCX files for all three documents.
- Added a complete ZIP bundle, component checksum manifest, and public SHA-256 manifest.
- Rebuilt the release page around the purpose of each file rather than a row of undifferentiated download buttons.
- Added an adoption path covering review, adaptation, pilot use, and controlled publication.
- Added visible release history.
- Added the journal practice note **The Device Is Not the Question** and connected it directly to the intake release.
- Added public journal labels for essays, practice notes, and studio notes.
- Extended site search to include journal type and tags.

## Technical changes

- Added reproducible DOCX source generation for the requester and implementation guides.
- Added intake-kit packaging and checksum generation scripts.
- Expanded repository validation for package files, companion previews, adoption steps, release history, related content, PDF signatures, DOCX archives, and ZIP integrity.
- Expanded structured data for free releases with version, modification date, downloadable distribution, and use-rights URL.
- Added responsive layouts for release-package cards, companion-document previews, adoption steps, release history, and related practice notes.

## Release files

The complete kit contains:

1. Intake request form, PDF and editable DOCX
2. Requester guide, PDF and editable DOCX
3. Implementation guide, PDF and editable DOCX
4. README, use terms, and component SHA-256 manifest

The authoritative public package is:

`static/downloads/forge-and-verse-digital-forensics-intake-kit-v1.1.zip`
